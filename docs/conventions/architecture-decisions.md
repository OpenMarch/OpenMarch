# Architecture Decisions

Create or update an [architecture decision record](../adr/README.md) before a
change establishes or alters any of these durable contracts:

- persistent schemas;
- file formats;
- Electron IPC contracts;
- public package APIs;
- security boundaries;
- cross-package ownership.

Capture the context, chosen boundary, consequences, and verification while the
decision is reviewable. Ordinary local implementation choices do not require an
ADR.
