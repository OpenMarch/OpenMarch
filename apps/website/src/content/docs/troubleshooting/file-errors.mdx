When OpenMarch can't open a show, it says why in a message. Find the message's title below.

## Invalid file permissions error

OpenMarch isn't allowed to read or write the file. You might see:

- <Ui k="fileAccessDialogError.forbidden.title" /> or "You do not have permission to open this file" when you open it.
- A spinner that never stops.
- An error such as "Error updating pages" when you change something, or changes that are gone the next time you open the show.

Give your user account permission to read and write the file, or move the file to a folder of your own, such as Documents, and open it from there.

### Windows

1. In File Explorer, right-click the file and select **Properties**.
2. Select the **Security** tab.
3. Under **Group or user names**, select your user account.
4. In the permissions list, check that **Read** and **Write** are allowed. If they aren't, or **Deny** is checked, ask whoever manages the computer to give you access.

### macOS

The first time OpenMarch opens a file in your Desktop, Documents or Downloads folder, macOS asks whether to allow it. If you chose not to, allow it in System Settings:

1. Open the Apple menu and select **System Settings**.
2. Select **Privacy & Security**, then **Files & Folders**.
3. Find OpenMarch and turn on the folder your show is in.

If that doesn't help, check the file itself:

1. In Finder, select the file, then choose **File › Get Info**.
2. Open **Sharing & Permissions** at the bottom of the window.
3. Select the lock and enter your password.
4. Set your user name to **Read & Write**.

Apple's [Mac User Guide](https://support.apple.com/guide/mac-help/mchlp1203/mac) explains permissions in more detail.

### Linux

1. Open a terminal in the folder that has the show.
2. Run `ls -l "my show.dots"` to see the file's permissions.
3. Run `chmod u+rw "my show.dots"` to give yourself read and write permission.

## File not found error

<Ui k="fileAccessDialogError.notFound.title" /> means there's no file at the place OpenMarch looked. This usually happens when you open a show from the start page's recent files after the file was moved, renamed or deleted.

1. Find the file where it is now, and open it with <Ui k="launchpage.files.openFile" /> on the start page.
2. Remove the old entry from <Ui k="launchpage.files.title" /> on the start page.

If you didn't open it from the recent files, [report it](/guides/start/get-help/).

## Update OpenMarch to open this file

<Ui k="fileAccessDialogError.tooNew.title" /> means the show was saved by a newer version of OpenMarch than the one you're using. The file hasn't been changed. Update OpenMarch, or [download the latest version](/download/), and open it again.

## Couldn't back up or convert your file

These appear when you open a show from OpenMarch 0.1.7, which 0.2 converts after saving a copy of it. In each case your file isn't changed.

- <Ui k="convertShow.openFailed.backupTitle" />: OpenMarch couldn't save the `.pre-conversion.dots` copy, so it didn't convert anything. The message says why. Most often the folder is read-only or you don't have permission to write in it, or the disk is full: move the show to a folder of your own, or free some space, and open it again. If the file is in use by another program, close that program first.
- <Ui k="convertShow.openFailed.convertTitle" />: the conversion failed and was undone. The message names the copy that was saved. [Report it](/guides/start/get-help/) and include the show if you can.

[Coming from OpenMarch 0.1](/guides/start/coming-from-0-1/) explains the conversion.

## Server error

<Ui k="fileAccessDialogError.server.title" /> comes from a problem inside OpenMarch, not from your file. [Report it](/guides/start/get-help/), and include the show if you can.

## "Unable to open file" error or render failure

The message says "Unable to open file", or OpenMarch shows <Ui k="fileAccessDialogError.renderFail.title" />. [Report it](/guides/start/get-help/), and include the show if you can.

If a show opens but you get errors while you edit it, try [repairing it](/troubleshooting/repair-a-file/).
