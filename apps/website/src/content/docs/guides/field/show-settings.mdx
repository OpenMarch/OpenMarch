Show settings hold a few numbers that belong to one show: where page and measure numbering starts, how long new pages are, and where the music starts. They're saved in the show file. Settings that apply to every show, such as the theme and shortcuts, are in the app's settings instead (see [Settings](/guides/reference/settings/)).

## Change a show setting

<Steps>

1. Select <Ui k="sidebar.settings" /> at the bottom of the sidebar.
2. Change the numbers you want.
3. Select <Ui k="workspaceSettings.saveChanges" />.

</Steps>

<Ui k="workspaceSettings.cancel" /> closes the panel without saving. <Ui k="workspaceSettings.resetToDefaults" /> puts every setting back to its default straight away, without waiting for Save.

## The settings

- <Ui k="workspaceSettings.pageNumberOffset" />: The first page's number. The default, 0, numbers pages 0, 1, 2 and so on; enter 1 to start at page 1. Every later page, subsets included, counts on from it.
- <Ui k="workspaceSettings.measurementOffset" />: The first measure's number. The default is 1. Enter 0 if the music starts with a pickup you want to call measure 0. To renumber from a measure partway through, use Edit music instead (see [Renumber measures](/guides/music/tempo/#renumber-measures)).
- <Ui k="workspaceSettings.defaultNewPageCounts" />: How many counts a page gets when you add one past the last page with the add-page pill on the timeline. The pill shows this number.
- <Ui k="workspaceSettings.audioOffsetSeconds" />: How many seconds after count 1 the music starts. It's the same value as the music offset in Edit music; see [Add the show's music](/guides/music/audio/#set-where-the-music-starts).
- <Ui k="workspaceSettings.defaultTempo" /> and <Ui k="workspaceSettings.defaultBeatsPerMeasure" />: The tempo and time signature chosen when the show was created. Changing them here doesn't change the show's counts; set the tempo and time signatures in Edit music ([Line the counts up with the music](/guides/music/tempo/)).
