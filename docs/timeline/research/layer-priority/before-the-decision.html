How layers work

Each marcher has stored rows: "follow this move from count A to count B, on layer L." Two rows for one marcher may overlap in time only on different layers, and the higher layer wins. The losing row isn't deleted. It keeps running underneath. When the higher row lets go, the marcher picks the lower move back up from wherever they actually are and finishes it on time, so nobody ever jumps.

The map: who picks the layer

Today each edit decides in its own file and nothing checks that they agree. Proposed, every edit names a rule from one list. Each row has its own marcher example further down.
