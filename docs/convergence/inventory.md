# Convergence inventory

Everything user-visible that the fork (`AlexDumo/OpenMarch-timeline` `main`) adds
on top of upstream `OpenMarch/OpenMarch` `main`, and what happens to each piece
before the fork merges upstream.

Marks:

- **Ship**: goes upstream as is.
- **Ship + work**: goes upstream after the listed work.
- **Hide**: code goes in with no UI; its schema still ships.
- **Park**: reverted on the convergence branch and kept on a saved branch.
  Nothing from it enters the file format.

Before any revert, fork `main` is saved as `archive/pre-convergence`.
