A show is one file, ending in `.dots`. It holds everything: the marchers and sections, the music and tempo, the field, the drill on the timeline, props, and the 3D View's venue and cameras. The desktop app saves on its own a few seconds after you stop editing, so there's no Save step to remember; see [How the desktop app saves](#how-the-desktop-app-saves). The web editor keeps shows in the browser instead; read [Keep shows safe in the web editor](#keep-shows-safe-in-the-web-editor) before you rely on it.

## The start page

When no show is open, OpenMarch shows the start page. Select <Ui k="launchpage.files.createNew" /> to start a show, or <Ui k="launchpage.files.openFile" /> to open one.

<Media
  id="files-launch"

  maxWidth={560}
/>

In the desktop app, <Ui k="launchpage.files.title" plain /> lists the shows you've opened, with a preview of each field; select one to open it. A show that was moved or deleted is marked <Ui k="launchpage.files.movedOrMissing" plain />. Each show has a button to <Ui k="launchpage.files.removeFile" plain />, and <Ui k="launchpage.files.clearMissingRecentFiles" /> and <Ui k="launchpage.files.clearAllRecentFiles" /> tidy the list. None of these delete files from your computer.

## Start a new show

<Steps>

1. Select <Ui k="launchpage.files.createNew" /> on the start page, or <Ui k="fileTab.newFile" /> in the toolbar's <Ui k="inspector.shape.fileTab" plain /> tab when a show is open.

2. Choose <Ui k="launchpage.newShow.steps.start.blank" />, or <Ui k="launchpage.newShow.steps.start.importPrevious" /> to start from another show's marchers, field and last set of positions.

3. Enter a <Ui k="launchpage.newShow.showName" plain /> and choose where to save the file. Then work through the remaining steps, or select <Ui k="launchpage.newShow.skip" /> on any you want to do later: the activity, the field, the marchers, the front ensemble, the music and the tempo. A show started from another show skips the field, the marchers and the front ensemble, since it takes them from that show.

4. Select <Ui k="launchpage.newShow.create" />.

</Steps>

[Write your first show](/guides/start/first-show/) walks through each step.

## Open a show

Select <Ui k="fileTab.openFile" /> in the toolbar's <Ui k="inspector.shape.fileTab" plain /> tab, or <Ui k="launchpage.files.openFile" /> on the start page, and choose a `.dots` file. In the desktop app, **File › Open File** in the app menu (<Kbd keys="Mod+O" />) does the same.

A show made in OpenMarch 0.1 opens after you confirm that it can be converted to timelines; see [Coming from OpenMarch 0.1](/guides/start/coming-from-0-1/). If a show won't open, see [File errors](/troubleshooting/file-errors/).

## Save a copy or close the show

Every change is saved to the show's file straight away. To take a change back, use Undo (<Kbd action="performUndo" />).

To keep a separate copy, for example before trying something big or to send to another staff member, select <Ui k="fileTab.saveFile" /> in the <Ui k="inspector.shape.fileTab" plain /> tab and choose where to save it. The copy is a whole show; the file you're working in stays open.

To close the show and go back to the start page, select <Ui k="fileTab.exitFile" />.

## How the desktop app saves

Your changes go to a private copy inside OpenMarch, and the show file is updated in one step: about 15 seconds after you stop editing (at most 30 seconds while you keep going), when you switch to another app, when you close the show, and when you choose **File › <Ui k="menu.file.saveNow" plain />** or <Ui k="workingCopy.saveNow" plain /> in the title bar. A sync app such as OneDrive, iCloud Drive or Dropbox never sees a half-written show or a `-journal` file next to it, so shows are safe to keep in folders they sync.

The title bar shows where the show stands. Select it for details and a <Ui k="workingCopy.saveNow" /> button.

| Title bar | Means |
| --- | --- |
| <Ui k="workingCopy.status.saved" plain /> | The show file has every change. |
| <Ui k="workingCopy.status.pending" plain /> | There are changes the show file doesn't have yet. They're kept safe and written in a few seconds. |
| <Ui k="workingCopy.status.saving" plain /> | The show file is being written. |
| <Ui k="workingCopy.status.problem" plain /> | OpenMarch couldn't write the show file, usually because a sync app or another program is using it. Your changes are kept safe, and OpenMarch keeps trying by itself. If the file is read-only, select <Ui k="workingCopy.saveAs" /> to save the show as a new file and keep working in it. |

If you close, quit or restart OpenMarch for an update while it can't write the show file, it asks first: try again, save as a new file, or <Ui k="fileDialog.unpublished.closeAnyway" plain /> and keep the changes for later.

If OpenMarch quits or the computer crashes before your last changes reach the file, they aren't lost. The next time you open that show, however you open it, OpenMarch asks whether to <Ui k="fileDialog.recoverOnOpen.recover" plain /> or <Ui k="fileDialog.recoverOnOpen.discard" plain />. The start page also lists them under <Ui k="workingCopy.recovery.title" plain />.

If the show file was changed by another program or computer since OpenMarch last saved it, for example by a sync app bringing in someone else's version, OpenMarch doesn't write over it. It asks whether to <Ui k="workingCopy.conflict.keepMine" plain />, <Ui k="workingCopy.conflict.keepTheirs" plain />, or <Ui k="workingCopy.conflict.saveCopy" plain />. <Ui k="workingCopy.conflict.keepMine" plain /> replaces the version you were asked about: if the file changes again before yours is written, OpenMarch asks again.

To go back to the way earlier versions saved, writing every change straight to the show file as you make it, turn off <Ui k="settings.general.workingCopySaves" /> in Settings › General. It applies to the next show you open. Keep it on for shows in a synced folder.

## Share a show

Send the `.dots` file itself, by email, a shared drive or a USB stick. The music is inside it, so the person you send it to doesn't need the audio file. They need the same version of OpenMarch or a newer one; see [Open a show in an older version](/troubleshooting/open-in-an-older-version/).

## Keep shows safe in the web editor

The web editor ([editor.openmarch.com](https://editor.openmarch.com)) keeps your shows in the browser, on this device. There's no account, and nothing is uploaded.

- Every change is saved in the browser as you work. The title bar shows <Ui k="web.savedInBrowser" plain /> and when you last backed up.
- The start page's <Ui k="web.library.tab" plain /> tab lists the shows kept in this browser; select one to open it. Each has a <Ui k="web.backUp" /> button and a menu with <Ui k="web.library.rename" />, <Ui k="web.library.duplicate" />, <Ui k="web.versionsMenu" /> and <Ui k="web.library.delete" />.
- The <Ui k="web.fileMenu" plain /> menu in the title bar has the file commands: new show, open a file, <Ui k="web.backUp" />, <Ui k="web.versionsMenu" />, export a video, send the show to On the Move, close, settings, and <Ui k="actions.ui.openHelp" />.
- <Ui k="launchpage.files.openFile" plain /> copies a `.dots` file from your device into the browser. Changes after that are saved in the browser, not to the file you picked.
- <Ui k="web.versionsMenu" /> lists earlier versions of the show: one is kept every couple of minutes while you edit and when you open the show, up to the last 20. Restoring one keeps the current state as a version too.

<Aside type="caution">
A browser can delete what it keeps for a site, for example when space runs low or when you clear your browsing data, and a private window keeps nothing after you close it. Select <Ui k="web.backUp" /> often: it downloads the show as a `.dots` file, or on a phone or tablet lets you save it to Files, a cloud drive or email. If you lose the device or the browser's data, your backups are the only copies. OpenMarch reminds you when a show has several days of changes that aren't backed up.
</Aside>

A backup is an ordinary `.dots` file: open it in the desktop app, or in the web editor in another browser or on another device. That's also how you move a show, since shows in one browser don't appear in another.

Use one tab. While OpenMarch is open in another tab, a second tab can't keep shows; the same goes for a private window. The editor says so when it happens, and you need to back up your work before you close that tab.

The web editor has most of the desktop app, but not PDF exports (coordinate sheets and drill charts) or repairing a file. Video export and sending a show to [On the Move](/guides/files/on-the-move/) work.

### On an iPad

Add OpenMarch to the Home Screen before you make shows: in Safari, select Share, then **Add to Home Screen**, and open OpenMarch from there from now on. Safari can delete shows kept in a tab if you don't visit for about a week; the Home Screen app keeps its shows. The Home Screen app and Safari keep separate lists, so back up any show you made in Safari and open the backup in the Home Screen app.
