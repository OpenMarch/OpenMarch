OpenMarch: On the Move is the phone app your marchers use to see their drill, coordinates and music. You send a show to it from the desktop app or the web editor. You need an OpenMarch account and an ensemble with a production to send it to; [Getting started with On the Move](/otm/getting-started/) explains how to set those up.

## What the phone app shows

The phone app gets each marcher's position at the end of every page, the set they reach on the page's last count, and draws a straight line from each page's set to the next. Anything the timeline does between page ends isn't sent:

- A move that starts or ends partway through a page arrives as a straight line from one page's set to the next.
- A curved path arrives as a straight line.

When your show has motion like this, the <Ui k="sidebar.mobile" plain /> panel says so below the controls for publishing the show. If marchers need to see a mid-page position on the phone, add a page at that count so it becomes a set (see [Pages](/guides/timeline/pages/)). Props aren't sent.

## Send a show for the first time

<Steps>

1. Open the show.

2. Select <Ui k="sidebar.mobile" /> (the phone) in the sidebar. You can also select <Ui k="exportCoordinates.exportButton" /> in the toolbar's <Ui k="inspector.shape.fileTab" plain /> tab and then the <Ui k="exportCoordinates.mobile" /> tab, or in the web editor, <Ui k="web.fileMenu" /> › <Ui k="actions.file.exportToMobile" />.

3. Select <Ui k="auth.signIn" />. OpenMarch's sign-in page opens in your browser (in the web editor, in a new tab). Sign in with your OpenMarch account, the same one you use on app.openmarch.com; if you don't have one, select <Ui k="mobileExport.signedOut.setupAccount" /> first. When you've signed in, go back to OpenMarch: the panel shows your account.

4. Choose the production for this show in your ensemble, and select <Ui k="ensembles.attachToProduction" />, then <Ui k="ensembles.attachDialog.attach" />. To make a new production, select <Ui k="ensembles.createProduction" />.

5. Select <Ui k="mobileExport.revision.publishButton" />, then <Ui k="mobileExport.confirmPublish.publish" />.

</Steps>

The show appears straight away for everyone in the ensemble.

## Signing in and out

OpenMarch remembers your sign-in, so you sign in once. In the web editor, the sign-in is shared with app.openmarch.com: if you're signed in there, the web editor already knows, and <Ui k="auth.signOut" /> in the panel's account menu signs you out of both. The desktop app keeps its own sign-in, so signing out in the browser doesn't sign it out.

If your browser blocks pop-ups, or you opened OpenMarch from your Home Screen, the web editor signs you in in the same tab and comes back to your show. It keeps your latest changes first, and asks before leaving only if it can't.

If the panel says <Ui k="exportCoordinates.webMobileUnavailable.title" plain />, you're in a test version of the web editor that can't sign in. Each version keeps its own shows, so select <Ui k="web.backUp" /> to save a `.dots` copy, then select <Ui k="exportCoordinates.webMobileUnavailable.openEditor" /> and open that file there, or open it in the desktop app.

If the panel says <Ui k="mobileExport.unreachable.title" plain />, OpenMarch couldn't reach its online service or confirm your sign-in. You stay signed in. Check your internet connection and select <Ui k="mobileExport.unreachable.retry" />.

If it says <Ui k="mobileExport.signInRejected.title" plain />, the online service turned your sign-in down. Select <Ui k="mobileExport.signInRejected.signOut" />, then sign in again.

## Send changes

After the first upload, each upload is a revision:

<Steps>

1. Select <Ui k="sidebar.mobile" /> in the sidebar.

2. Under <Ui k="mobileExport.revision.newTitleLabel" plain />, describe what changed. Marchers don't see this; it's for you and your staff.

3. Select <Ui k="mobileExport.revision.pushButton" />.

</Steps>

The panel lists every revision under <Ui k="mobileExport.revisions.listHeading" plain />.

## Music and background

- <Ui k="mobileExport.audio.title" plain />: the show's music is uploaded with it. <Ui k="mobileExport.audio.addAlternate" /> adds another recording, such as a slower rehearsal track, that marchers can choose in the app. <Ui k="mobileExport.audio.setActive" /> picks the one the app plays by default.
- The field image is uploaded as the app's background with each revision. To change it, change the field image in the show's field settings and push a revision.

To stop uploading from this file to the production, open <Ui k="mobileExport.settings.button" /> in the panel and select <Ui k="mobileExport.detach.button" />.
