OpenMarch has two editor modes. <Ui k="settings.general.editorMode.basic" /> works in pages, like a drill chart. <Ui k="settings.general.editorMode.expert" /> shows the full timeline, where moves can cross pages and overlap. Both edit the same show, and you can switch at any time.

The mode belongs to the app, not to the show. Switching never changes the open show, and a show made in one mode opens in the other.

## Basic

In Basic, the timeline is one row of page boxes. Each box is as long as its page, with the page's counts and the music inside it.

<Media
  id="start-timeline-basic"
  alt="The timeline in Basic: one row of numbered page boxes, each holding its counts, measures and a stretch of the music's waveform, with the playback controls along the top."
/>

You set each page: select a page, and arrange the marchers where they should be when the page ends. A marcher you don't move on a page stays where the last set left it, and follows along if you change that set later.

You can also set a position in the middle of a page. Put the playhead on a count inside the page and move the marcher there. The page box gets a tick at that count, and the marcher still reaches the page's set at the end of the page. To take that position out again, right-click the tick and select <Ui k="timeline.basic.point.remove" />.

Adding a page, or splitting one, keeps everyone's positions where the new page starts, so no move runs across the new page line.

Play (<Kbd action="playPause" />) plays from the start of the page you're on to the end of the show.

## Expert

Expert shows the full timeline. A move that fills a page is that page's box, as in Basic. A move that doesn't line up with the pages, such as one that starts mid-page, crosses a page line or moves only some marchers, gets its own bar under the pages, so you can see and change when it starts and ends.

<Media
  id="start-timeline-expert"
  alt="The timeline in Expert: the same pages, with page 2 selected between the yellow start flag and the playhead, a move for a few marchers drawn as a bar under the pages, and Loop and compact timeline buttons in the playback controls."
/>

Everything Basic does works the same way in Expert. Expert adds:

- Moves as bars you can drag, resize, split, merge and rename, including moves that cross page lines and moves that overlap.
- Selecting a stretch of counts by dragging along the timeline, and double-clicking a move to work on it alone.
- The start flag, which you place to choose where playback starts. Play plays from the start flag to the playhead, and <Kbd action="playOn" /> plays on to the end of the show.
- The loop, which repeats a stretch while you work (<Kbd action="toggleLoop" />).
- <Ui k="timeline.terms.holdOverWindow" />, which keeps marchers still between the start flag and the playhead. In Expert, a drag on a later page of a hold ends the hold there; see [Drag marchers that are Held](/guides/timeline/defined-held-not-defined/#drag-marchers-that-are-held).
- Resizing the timeline by dragging its top edge, and the compact timeline.

[How the timeline works](/guides/timeline/how-the-timeline-works/) explains moves and the start flag.

## Shows edited in Expert, opened in Basic

Some moves made in Expert can't be shown as pages: a move that crosses a page line, moves that overlap, a move into a shape, or a move along a curve. Basic keeps them, plays them and draws them, but doesn't change them.

A page with such marchers shows an E in its page box; point at it to see how many marchers it is. If you move a group that includes them, the others move and they stay, and a message says so with a <Ui k="timeline.basic.switchToExpert" /> button.

## Choose a mode

The first time you open OpenMarch, it asks how you want to work. Choose Basic if you write drill page by page, as on a paper chart, or Expert if you want moves that span pages.

To switch later:

1. Open <Ui k="settings.title" /> (<Kbd action="openSettings" />).
2. Select <Ui k="settings.timeline" />.
3. Under <Ui k="settings.general.editorMode" />, choose <Ui k="settings.general.editorMode.basic" /> or <Ui k="settings.general.editorMode.expert" />.

<Media
  id="start-editor-mode-setting"
  alt="The Settings window on the Timeline section, with Editor mode at the top as two cards, Basic and Expert, each with a small picture of its timeline, and the Waveform choices below."
/>

The open show changes at once, with no reload. The keyboard shortcuts list, the command palette and the Playback menu leave out what Basic doesn't have.
