OpenMarch has two editor modes. <Ui k="settings.general.editorMode.basic" /> works page by page, like a drill chart. <Ui k="settings.general.editorMode.expert" /> shows the full timeline, where a <Term id="move">move</Term> can start on any count, cross pages and overlap another. [How the timeline works](/guides/timeline/how-the-timeline-works/) explains pages, moves and the start flag.

The mode belongs to the app, not to the show. Switching never changes the open show, and a show made in one mode opens in the other.

## How the modes differ

| | Basic | Expert |
| --- | --- | --- |
| The timeline | One row of page boxes, each with its counts and music. | The page boxes, with a bar under them for each move that doesn't fill a page. |
| Where Play starts | At the start of the page the playhead is on, playing on to the end of the show. | At the <Term id="start-flag">start flag</Term>, which you place. Play stops at the playhead, and <Kbd action="playOn" /> plays on. See [Play the show](/guides/timeline/play-the-show/). |
| Moves | Each page has its move. A position in the middle of a page splits it at that count. | Moves start and end on any count, cross pages, cover some marchers and overlap. You drag, resize, split, merge and rename their bars. |
| Dragging the playhead | Lands on every count. | Lands on measures and pages' flags when it's near one; hold <Kbd keys="Alt" gesture="drag" /> for any count. |
| Expert-only tools | Not available. | [Selecting a stretch of counts](/guides/timeline/moves/#make-a-move) (<Kbd keys="Mod" gesture="drag" />), [the loop](/guides/timeline/play-the-show/#loop-a-passage) (<Kbd action="toggleLoop" />), [working on one move alone](/guides/timeline/moves/#work-on-one-move-alone), [<Ui k="timeline.terms.holdOverWindow" plain />](/guides/timeline/holds/#hold-from-the-start-flag-to-the-playhead), [dragging the timeline's top edge to make it taller, and the <Ui k="timeline.compact.label" plain /> button](/guides/timeline/play-the-show/#zoom-scroll-and-resize-the-timeline). |

Everything Basic does works the same way in Expert.

## Basic

You set each page: select its box, and put the marchers where they should be when the page ends. A marcher you don't move on a page stays where the last set left it.

To put a marcher somewhere in the middle of a page, move it with the playhead on that count; see [Set a position in the middle of a page](/guides/timeline/moves/#set-a-position-in-the-middle-of-a-page-basic). Adding or splitting a page keeps everyone's positions where the new page starts.

## Expert

Expert adds a bar for every move that doesn't fill a page, such as one that starts mid-page or moves only some marchers, so you can see and change when it starts and ends. [Make and change moves](/guides/timeline/moves/) covers making and changing them.

## Shows edited in Expert, opened in Basic

Some moves made in Expert can't be shown as pages: a move that crosses a page's flag, moves that overlap, a move into a shape, or a move along a curve. Basic keeps them, plays them and draws them, but doesn't change them. Other Expert moves, such as some marchers split off into a move of their own inside one page, Basic edits like any page's move; [Known issues](/troubleshooting/known-issues/#basic-can-take-a-marcher-out-of-a-move-made-in-expert) has the one case to watch.

A page with such marchers shows an E at the start of its box; point at it to see how many marchers it is. If you move a group that includes them, the others move and they stay, and a message says so with a <Ui k="timeline.basic.switchToExpert" /> button.

## Switch between Basic and Expert

The first time you open OpenMarch, it asks how you want to work. Choose Basic if you write drill page by page, as on a paper chart, or Expert if you want moves that span pages. To switch later:

1. Open <Ui k="settings.title" /> (<Kbd action="openSettings" />).
2. Select <Ui k="settings.timeline" />.
3. Under <Ui k="settings.general.editorMode" />, choose <Ui k="settings.general.editorMode.basic" /> or <Ui k="settings.general.editorMode.expert" />.

Or open the command palette (<Kbd action="openCommandPalette" />), type "basic" or "expert", and select <Ui k="actions.timeline.toggleEditorModeToExpert" /> or <Ui k="actions.timeline.toggleEditorModeToBasic" />.

The open show changes at once. The keyboard shortcuts list, the command palette and the Playback menu leave out what Basic doesn't have.
