These menus are in the desktop app. On a Mac they're in the menu bar at the top of the screen. On Windows and Linux, select <Ui k="titlebar.menu" /> at the start of the title bar to open them. The web editor doesn't have these menus; its own <Ui k="web.fileMenu" /> menu, at the start of the title bar, holds creating, opening and backing up shows, Settings and Help.

The two systems' menus differ: a Mac has an OpenMarch menu with About, Hide and Quit, more items in Edit, and its own Window menu. The page shows your system's menus; use the switch to see the other one. Keys are shown the way each system writes them: on a Mac, ⌘ is Command, ⌥ is Option, ⇧ is Shift and ⌃ is Control.

Items marked Expert are left out of the <Ui k="menu.playback.title" /> menu in [Basic mode](/guides/start/basic-and-expert/). The menus hold only some of the app's commands: [Keyboard shortcuts](/guides/reference/keyboard-shortcuts/) lists the shortcuts, and <Ui k="menu.help.title" /> › <Ui k="menu.help.showShortcuts" /> shows them in the app.

The File menu's items are the same commands as the buttons on the toolbar's <Ui k="inspector.shape.fileTab" plain /> tab, under other names; [Save and open shows](/guides/files/save-and-open/#the-file-tab-and-the-file-menu) explains them:

| File menu | File tab |
| --- | --- |
| <Ui k="menu.file.open" plain /> | <Ui k="fileTab.openFile" plain /> |
| <Ui k="menu.file.createNew" plain /> | <Ui k="fileTab.newFile" plain /> |
| <Ui k="menu.file.saveAsCopy" plain /> | <Ui k="fileTab.saveFile" plain /> |
| <Ui k="menu.file.closeFile" plain /> | <Ui k="fileTab.exitFile" plain /> |

Most items in the OpenMarch (Mac), Edit, View and Window menus are the system's own, such as Copy, Reload and Minimize, and work as in any app.
